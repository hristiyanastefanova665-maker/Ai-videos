# KATANA — българска моушън графика (Remotion)

Самостоятелна анимация 1080 × 1920, 30 FPS, 46 s, H.264 MP4. Всичко е генерирано с код (React + Remotion + SVG + CSS). Няма видеозаписи, скрийншоти или стоково съдържание.

## Резултати

| Файл | Описание |
|---|---|
| `out/katana-bg.mp4` | Финалното видео без звук (място за вашия глас) |
| `out/katana-bg-vo.mp4` | Същото видео, смесено с `assets/voiceover.mp3` (за преглед на синхрона) |
| `out/preview.gif` / `out/sheet.png` | Бърз преглед |

## Изисквания и стартиране

- Node.js 18+ (тествано с 22), npm, FFmpeg (само за смесване на гласа)
- Remotion използва Chromium. Ако имате инсталиран Chrome, той се ползва автоматично; иначе задайте `CHROME_PATH=/път/до/chrome`.

```bash
npm install
npm run studio          # интерактивен преглед в браузъра (Remotion Studio)
npm run render          # → out/katana-bg.mp4
npm run render:vo       # → също out/katana-bg-vo.mp4 с гласа от assets/voiceover.mp3
npm run stills          # PNG кадри за бърза проверка → out/stills/
node render.mjs --frames=390-593   # рендер само на част (напр. сцена 4)
```

## Как да променя…

Всичко, което се променя често, е в **`src/config.ts`**.

### Текст
Обектът `T` съдържа всички надписи по сцени. Думите в `[квадратни скоби]` в полетата `caption` се осветяват в лайм кутия, например:

```ts
caption: 'Дадох му [този] промпт:'
```

Промптът, който се „пише“ буква по буква, е в `T.prompt.text`. Осветените думи в него са в `T.prompt.highlights` (трябва да съвпадат точно с текста).

Картите за спестено време са в `T.time.cards` (`{t: 'СЛОЕВЕ', h: 3}`). Ако промените часовете, сменете и `T.time.big` и броячът в `S8Time.tsx` (`0 → 9`).

### Тайминг
`SCENES` задава началния кадър (`from`) и продължителността (`dur`) на всяка сцена в кадри (30 кадъра = 1 s). Сега сцените са рязани по паузите в гласа (3.8 s, 7.7 s, 13.0 s, 19.8 s, 24.5 s, 29.4 s, 32.6 s, 38.0 s). Ако промените продължителност:

1. Сменете `dur` на сцената.
2. Изместете `from` на следващите сцени.
3. Обновете `TOTAL_FRAMES` (= `from + dur` на последната сцена).

Вътрешният тайминг на всяка сцена е в нейния файл в `src/scenes/` — числата в `a(f, начало, край, от, до)` са кадри спрямо началото на сцената.

### Цветове
`C` в `src/config.ts`:

```ts
bg: '#080B0D', bg2: '#101820', lime: '#C8FF00', white: '#F4F4F4', grey: '#7D8790'
```

Смяната на `lime` сменя всички неонови акценти, сиянието и надписите.

### Шрифтове
`FONT` в `src/config.ts`. Файловете (с кирилица) са в `public/fonts/` и се зареждат от `src/fonts.ts`: Oswald (заглавия), Unbounded (акценти), JetBrains Mono (интерфейс).
