# Hristiyana Creative – 20s vertical commercial

`out/hristiyana-creative-20s.mp4` — 1080×1920, 30 fps, 20 s, with soundtrack.

Re-render after editing `index.html` (GSAP timeline):

    npm install
    node render.js                 # full video
    node render.js stills 1.2 5.6  # preview frames at given seconds

Open `index.html#play` in a browser and click for a live preview with audio.
